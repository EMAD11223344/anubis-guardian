𓃣 Anubis Guardian

Deterministic security auditor for AI-built projects — built for the vibe-coding era.

Codebase Mode (offline, static-only) + URL Mode (passive-first, ownership-gated). MIT licensed.

Deterministic

Same input → byte-identical report. CI-safe, review-safe, diff-able.

Honest scoring

100 − (25C + 10H + 4M + 1L) with root-cause caps. Low-confidence never deducts.

No auto-fix

Suggested diffs + generated tests only. A human applies every change.

Legal URL Mode

L1 is browser-equivalent passive. L2+ requires verified ownership (DNS TXT / .well-known).

Quick start

npm install -g @anubis-guardian/cli
anubis-guardian scan ./my-ai-project --format all --fail-on critical
anubis-guardian scan-url https://staging.example.com --level 1     # passive
anubis-guardian ownership https://staging.example.com              # get a nonce → verify → L2/L3
anubis-guardian init-ci && anubis-guardian init-hook               # CI gate + agent guard

Guarantees

  • Never executes project code · never auto-applies a fix · never prints a full secret.
  • CRITICAL only from deterministic, verified evidence — AI/probe findings are capped and flagged.
  • Every report carries an authorization record (URL Mode) and a coverage registry (what ran, what didn't).
